# Monthly Sales Trend Analysis(SQLite)

## Objective

The purpose of this project is to analyze monthly sales performance by calculating revenue and order volume trends using SQL aggregation functions. The analysis helps identify sales patterns, seasonal trends, and overall business performance over time.

## Dataset

**Sample Superstore Dataset**

## Tools Used

* SQLite
* DB Browser for SQLite
* GitHub

## Project Features

* Monthly revenue analysis using SQL aggregations
* Monthly order volume analysis using distinct order counts
* Time-based trend analysis using year and month grouping
* Identification of top-performing sales periods

## Key Insights

* Revenue fluctuates across different months, indicating varying customer demand.
* Certain months generate significantly higher sales compared to others.
* Order volume generally follows the same pattern as revenue trends.
* Monthly aggregation provides a clear view of business performance and seasonality.

## Outcome

Successfully analyzed sales trends using SQLite by grouping transaction data by year and month. Generated monthly revenue and order volume reports that help understand sales performance and support data-driven business decisions.
